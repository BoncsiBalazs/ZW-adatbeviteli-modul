# ZeroWaste Entry 5.3 – GitHub Pages

1. A helyben tárolt adatokról készítsen ZIP-exportot, majd mentse a jelenlegi repozitóriumot.
2. A teljes 5.3-as ZIP tartalmát (nem magát a ZIP-fájlt) töltse fel a **BoncsiBalazs/ZW-adatbeviteli-modul** repozitórium **gyökérkönyvtárába**.
3. Cserélje le az azonos nevű fájlokat, és töltse fel az új `icons/` mappát is.
4. GitHub: **Settings → Pages → Deploy from a branch → main / (root)**. Ellenőrizze a ténylegesen megjelenő Pages-címet.
5. Frissítsen Ctrl+Shift+R-rel. A PWA-gyorsítótár verziója: `adatrögzítő-modul-v5-3-anon`, az erőforrásoké `5.3.0`.
6. Próbálja ki az Igen/Nem komponensértékelést, a JAR új szövegeit, a letisztított felületet és a ZIP-exportot.

A korábbi szakdolgozati **BoncsiBalazs/zerowaste-entry** repozitórium nem módosítandó.
